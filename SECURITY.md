# Security Policy

Event Quality Gate is a local validation tool and makes no network requests. Treat contracts and JSONL inputs as untrusted data, not instructions.

Do not use real customer identifiers, authentication tokens, cookies, or proprietary production events in issues or fixtures. Reports may echo invalid values in future versions, so review generated artifacts before publishing them.

For a security concern, use GitHub's private vulnerability reporting feature when available. Do not open a public issue containing secrets or exploitable details.
